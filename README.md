# The Hollow

A deck-building hex RPG prototype: craft spells from runes between battles,
then fight a 5-round battle on a 7x7 hex grid. Built first as a single-device
browser prototype; the end target is a Discord Activity.

```bash
npm ci
npm run dev     # the prototype at http://localhost:5173
npm run check   # everything CI runs
```
